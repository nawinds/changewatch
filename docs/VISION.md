# Назначение ChangeWatch

ChangeWatch отслеживает изменения значений в публичных Google Таблицах.
Основной сценарий — наблюдение за своими баллами в учебной ведомости.

Пользователь подключает таблицу по `spreadsheetId` и `sheetId`, выбирает строку по ключевому
столбцу и значению, указывает столбцы и правило изменения. Сервер периодически получает
CSV через Google Sheets export и сохраняет историю со старыми и новыми значениями.
Первое чтение создаёт базу; последующие чтения сравниваются с ней.

Несколько пользователей одной таблицы используют общий источник и одну загрузку.
У каждого остаются свои мониторы, правила и история. Монитор можно поставить на паузу или удалить.

Продукт ограничен мониторингом Google Таблиц. Поддержки произвольных URL, веб-страниц,
HTML/CSS-селекторов и сторонних HTTP API нет. CSV-разбор нужен только для чтения экспорта таблицы.
Закрытые таблицы, OAuth, доставка уведомлений и отдельный клиент не входят в текущий объём.

Приложение работает одним сервером с PostgreSQL. Сценарии API и запуск описаны в
[README](../README.md), устройство модулей — в [ARCHITECTURE.md](ARCHITECTURE.md).
